# Aturan Kerja & Penghematan Token

- **Eksplorasi Efisien**: Gunakan alat pencarian (`grep`, `glob`, LSP) terlebih dahulu sebelum membuka file. Dilarang membaca file besar secara utuh; wajib baca per rentang baris (`offset` & `limit`).
- **Edit Minimalis**: Saat mengedit file, wajib gunakan metode diff/patch pada baris terkait saja. Dilarang menulis ulang seluruh isi file.
- **Filter Folder**: Abaikan folder `node_modules`, `.git`, `dist`, `build`, dan semua file lock (`package-lock.json`, `yarn.lock`, `pnpm-lock.yaml`, `bun.lockb`).
- **Gaya Komunikasi**: Berikan jawaban singkat, padat, dan langsung ke solusi tanpa penjelasan basa-basi yang panjang.
